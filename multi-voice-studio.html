CyborgMM အသံချည်းပဲ (၃၁ သံ) သုံးတယ်။
အလုပ်လုပ်ပုံ: Segment တစ်ခု = အသံတစ်သံ + စာသား → တစ်ပိုင်းချင်း (၁,၀၀၀ စာလုံးအတွင်း) ထုတ် → WAV တစ်ခုတည်း ဆက်ပေး။ Document တင်ရင် browser ထဲမှာပဲ စာသားထုတ်ပြီး အပိုင်းခွဲပေးတယ် (server ကို ဖိုင်မတင်ဘူး)။ Project သိမ်းတာက ဒီ browser ထဲမှာပဲ (localStorage) — member cloud save က နောက်အဆင့်။
⚡ အသံထုတ်တာက Fast Server window ချိန်မှာပဲ ရတယ် (တနင်္လာ–သောကြာ 15:00–19:00, စနေ–တနင်္ဂနွေ 15:00–21:00 Myanmar Time)။

၁။ အသံထုတ်လမ်း (Generation route)

၂။ Document တင် → Segment ဖြစ်

TXT/MD = တိုက်ရိုက်, DOCX/EPUB = ZIP ထဲက စာသားထုတ်, PDF = စာသားပါတဲ့ PDF ပဲ (scan ဓာတ်ပုံ PDF ဆို OCR လိုမယ်, ဒီမှာ မပါဘူး)။
