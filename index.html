SRT / စာသားကို Gemini AI နဲ့ မြန်မာ ဘာသာပြန် ပေးတယ်၊ ဒါမှမဟုတ် transcript ကနေ Recap narration စာသား အလိုလို ထုတ်ပေးတယ် — Recap App ထဲက AI ပုံစံ အတိုင်း၊ ကိုယ့် Gemini API Key (BYOK) နဲ့ သုံးရတယ်။ ကျွန်တော်တို့ proxy ကနေ ချိတ်တာမို့ VPN မလိုပါ။

🔑Gemini API Key ကိုယ့် key နဲ့ AI စာသား ထုတ်မယ်

Key က သင့် browser ထဲမှာပဲ သိမ်းထားပါတယ် — ကျွန်တော်တို့ server မှာ မသိမ်း၊ မမြင်ရပါ။ Key မရှိရင် Google AI Studio (aistudio.google.com/apikey) မှာ အခမဲ့ ယူလို့ရပါတယ်။ VPN မလိုပါ — ကျွန်တော်တို့ proxy ကနေ ချိတ်ပေးပါတယ်။
